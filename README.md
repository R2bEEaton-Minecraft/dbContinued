# Dave's Building Continued

Dave's Building Continued is a NeoForge 1.21.1 continuation of Dave's Building Extended, ported by R2bEEaton and BubbyCraft. It adds vanilla-friendly industrial, rail, factory, ambience, and Create-focused decoration.

Future updates may explore more survival-friendly recipes and progression, expanded Create and train integration, and other community-requested blocks and quality-of-life improvements.

For development, open the workspace in MCreator or run `gradlew.bat runClient` on Windows (`./gradlew runClient` elsewhere).
